## Anchor text rules

- Service page links use descriptive anchors with the service and place, for example "Newcastle shopfitting" or "Central Coast office fitouts". Do not use "click here".
- Vary anchors across posts. The same service page should not receive the identical anchor from more than three posts.
- Blog-to-blog links use the target post's topic, for example "Newcastle decking cost guide".
- `/quote` always uses "Get a free measure and quote".
