## Anchor text rules

- Service page links use descriptive anchors with the service and place, for example "Hunter Valley custom kitchens". Do not use "click here".
- The same service page should not get the identical anchor from more than three posts.
- Blog-to-blog links use the target post's topic.
- `/quote` always uses "Get a free measure and quote".
