Kitchen cabinet cost per linear metre in NSW is commonly an indicative 2026 range from $800–$1,400 in laminate to $2,200–$4,000 plus in timber, with polyurethane and two-pack sitting between those bands ([LeadKit](https://www.leadkit.com.au/blog/kitchen-renovation-cost-sydney-2026)). The unit helps compare a run of cabinetry, but it lies if the quote does not say what is inside it. A metre of overhead cupboards is not a metre of drawer-heavy base cabinets, and neither includes a waterfall island by default.

The calculation is useful when used honestly. Measure the room, separate bases from overheads and tall units, then add surface, appliances, installation and trades. That turns a vague “per metre” promise into a budget you can interrogate.

## FAQ

### What is a linear metre in cabinetry pricing?

A linear metre is one metre measured along the run of cabinetry. It is a useful estimator only when the quote states whether it covers base cabinets, overheads, tall units, drawers, hardware, panels, installation and GST. The useful next step is a measured layout and a written inclusion list, rather than selecting from a generic rate alone.

### How much per linear metre for a custom kitchen in NSW?

Market ranges commonly run from about $800–$1,400 per linear metre for laminate cabinetry to $2,200–$4,000 plus for timber. A real kitchen combines different unit types, so use the rate as a budgeting guide rather than multiplying one number blindly. The useful next step is a measured layout and a written inclusion list, rather than selecting from a generic rate alone.

### Does the per-metre price include the benchtop?

Usually not unless it is expressly itemised. Benchtops are measured, fabricated and installed as a separate surface package, especially where stone, porcelain, cut-outs, waterfall ends or splashbacks are involved. The useful next step is a measured layout and a written inclusion list, rather than selecting from a generic rate alone.

### Why is two-pack more per metre than laminate?

Two-pack costs more because it involves prepared panels and specialist spray finishing, and often appears on profile-heavy door sets. The difference is not simply paint; it is a different manufacturing and finishing process. The useful next step is a measured layout and a written inclusion list, rather than selecting from a generic rate alone.

### Do overhead cupboards cost the same per metre?

No. Overheads commonly cost less per metre than drawer-heavy base cabinets because they use less load-bearing cabinet structure and fewer drawer systems. Tall units and pantry pull-outs can cost more because of their height, doors and internal hardware. The useful next step is a measured layout and a written inclusion list, rather than selecting from a generic rate alone.

### How do I estimate my own kitchen from a measurement?

Measure each wall run, separate bases, overheads and tall units, then apply a relevant market band to each category. Add benchtops, appliance housings, panels, hardware upgrades, installation and trades separately. A measure is a starting brief, not a manufacturing drawing. The useful next step is a measured layout and a written inclusion list, rather than selecting from a generic rate alone.
